## 🕳️ The Chasm  
The Chasm is a vast, living dungeon that shifts with every descent. No two runs are the same. Each level features procedurally generated biomes filled with unique enemies, traps, secrets, and lore.

The Chasm is alive. Each run offers a new layout, new dangers, and new discoveries. Permadeath ensures that each choice matters — learn, adapt, and go deeper next time.
